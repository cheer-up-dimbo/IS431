## Examiner Guidance

The following questions reflect what examiners expect the report to address. They are not chapter titles. Use them as a checklist when reviewing your draft -- every item should be answered somewhere in the report.

### Context

- [ ] Is the project background clearly introduced (motivation, collaborators or sponsors if any, constraints)?
- [ ] Is there a clear problem statement / design brief with a stated project objective and scope?

### What is the problem?

- [ ] Is there an overview of the relevant domain and market/technology trends?
- [ ] Are key terms and frameworks defined clearly?
- [ ] Are pain points or user needs identified and supported by evidence (e.g. reviews, surveys, interviews, observation)?
- [ ] Are key insights distilled from the needs-finding data?
- [ ] Is there a review of existing solutions that highlights gaps and upcoming trends?
- [ ] Are the gaps and opportunities clearly articulated?
- [ ] Is the refined project direction and scope stated?

### What is your proposed solution?

- [ ] Is there a user journey or workflow map that highlights issues and opens up the solution space?
- [ ] Are the ideas explored presented (initial concepts, new concepts, iterations)?
- [ ] Were preliminary prototypes used to evaluate candidate ideas?
- [ ] Is the final concept selection justified (e.g. decision matrix)?
- [ ] Are measurable performance criteria defined?

### What did you build to test your solution?

- [ ] Is the system architecture presented (high-level block diagram)?
- [ ] Is each major subsystem described in sufficient detail?
- [ ] Is the integration of subsystems explained (hardware and/or software)?

### What did you learn from your tests?

- [ ] Are subsystem-level test results presented?
- [ ] Are system-level test results presented?
- [ ] Is the user testing procedure described (if applicable)?
- [ ] Are user testing results reported?
- [ ] Is there a performance assessment against the criteria defined in the proposed solution?
- [ ] Are limitations stated honestly?

### What's next?

- [ ] Is there a reflection on the design process?
- [ ] Are future work and potential applications discussed?
- [ ] Are conclusions drawn that map back to the original objective?
