6. Discussion and Future Work

6.1 Discussion

User Interface. The GUI passed all five functional requirements (GUI-1 through GUI-5), including multi-user data isolation, real-time session display, and hardware-independent development. The phone dashboard was developed as a companion interface after the CDE AI Fair revealed that touchscreen interaction with gloved hands was impractical.

Upper Mechanism. The 2-DOF coaxial differential arms, multi-layer padding with IMU sensing, and the CAN bus motor control architecture were validated through iterative prototyping. Arm strike speed (RM-5) and IMU impact detection rate (RM-6) are pending verification with the fully integrated prototype.

Lower Mechanism. The base passed stability testing (RM-1) with a factor of safety exceeding 1.5, and single-person portability (RM-7) was confirmed. Height adjustment stroke (RM-3) and yaw angular velocity (RM-4) are defined but pending verification. System integration tests (coordinated motion, loaded sparring, power budget) require the completed prototype.

Robot Intelligence. All seven Robot Intelligence requirements were verified. The dual-branch (voxel + pose) Transformer exceeded its 90% accuracy target (RI-3, 96.8% on an unseen person) and met the 150 ms end-to-end latency requirement (RI-2, ~120 ms). CV+IMU sensor fusion (RI-4), all five adaptive sparring styles (RI-6), and the on-device Qwen2.5-3B LLM coach (RI-7) were validated through both automated tests and the CDE AI Fair real-world deployment. The fair also drove the largest design pivot of the project: the unreliable HSV colour-tracking prototype was replaced from scratch with the Transformer-based action recognition model that now powers the deployed system.

6.2 Current Limitations

Subsystem Limitation Impact
User Interface No formal usability testing with target users GUI was validated functionally and at showcases, but structured user studies with boxers of varying skill levels have not been conducted
Upper Mechanism Fixed head-torso pad separation (30 cm) Anatomical head-torso gap varies 26 to 33 cm across the 150 to 190 cm user range; fixed spacing is a compromise
Pending arm strike speed verification (RM-5) 90-degree strike in 0.25 s or less has not been measured on the integrated prototype
Lower Mechanism No linear forward/backward movement Robot cannot advance or retreat to maintain realistic sparring distance; limits footwork simulation
Robot Intelligence CV model training scope is narrow (8 classes, no retraction) The action prediction model only labels 6 punch types, block, and idle, and its punch annotations stop at full extension. This caps what the system can recognise (no slips, no head-vs-body targets, no footwork) and forces the IMU + pad-constraint filter to absorb the model's wobble during the retraction phase rather than the CV model being correct end-to-end
Pose estimator not trained for boxing YOLO Pose is pretrained on COCO where hands are bare, so it has no concept of gloved hands or this camera angle. The wrist keypoints become unreliable exactly when they matter most (at punch extension), and the model is forced to lean on the voxel branch instead of getting two strong signals — capping how much further the fused architecture can be pushed
LLM compute ceiling on the Jetson The Jetson has 16 GB of memory but its GPU isn't built to run a heavy LLM in parallel with the CV pipeline. A 3B model with a 128-token output cap is the largest the current hardware can sustain without hurting the real-time loop — which limits how deep the post-session coaching analysis can go and how specific the drill suggestions can be

6.3 Recommendations for Future Work

Area Recommendation Rationale
User Interface Conduct structured user testing with boxers Formal usability studies across beginner, intermediate, and advanced boxers would validate training effectiveness and identify UX improvements
Upper Mechanism Variable head-torso pad separation A secondary actuator or adjustable rail would scale the head-torso spacing with user height (26 to 33 cm), improving anatomical accuracy
TPU lattice padding replacement A single-piece TPU honeycomb print could replace the foam, spring, and PLA mount, reducing part count and providing tuneable dampening (Di Caprio et al., 2025)
Lower Mechanism Add linear translation (forward/backward axis) Enables the robot to maintain or close distance, replicating a real opponent's ring movement and creating pressure-based training scenarios
Robot Intelligence Expand the CV model's training scope Add an explicit retraction class so the CV model is correct end-to-end and the IMU filter no longer has to absorb the retraction wobble. Then expand the action set with slips, head/body targets, and defensive footwork — richer labels feed every other part of the system (sparring AI, analytics, LLM coach) and unlock more dynamic feedback
Fine-tune a custom pose estimator on boxing footage Manually annotate keypoints on our own recorded footage (gloved hands, this camera viewpoint) and fine-tune YOLO Pose on it. A pose model that was actually trained for the context would let the pose stream pull its own weight instead of relying on the voxel branch to compensate, lifting the ceiling on the fused architecture
Upgrade the LLM compute path Several upgrade paths preserve the “everything local” principle while unlocking richer post-session coaching from a larger 7B–8B model: a more powerful Jetson (Orin AGX), a dedicated discrete GPU for the LLM, or a USB AI accelerator (e.g. Hailo, Coral) to offload LLM inference
System-Level Complete pending RM-3, RM-4, RM-5, RM-6 verification Height stroke, yaw velocity, strike speed, and impact detection tests are defined but require the fully integrated prototype

6.5 Conclusion

Project Outcome. BoxBunny addresses the gap identified in Chapter 2: no existing product consolidates adaptive fight intelligence, structured skill progression, realistic sparring, modular hardware, and performance analytics into a single platform. Of the 19 verification criteria defined across all subsystems, 15 have been verified and passed, with four mechanism-level requirements (RM-3 to RM-6) pending full prototype integration.

Subsystem Contributions. The User Interface delivers four training modes, multi-user accounts, and a phone dashboard across 24 GUI pages and 10 Vue views. The Upper Mechanism provides 2-DOF coaxial differential arms with impact-sensing padding. The Lower Mechanism provides a stable base (FoS exceeding 1.5), yaw rotation, and screw-jack height adjustment. The Robot Intelligence layer runs entirely on a Jetson Orin NX as 10 ROS 2 nodes: a dual-branch (voxel + pose) Transformer classifies 8 punch types at 96.8% on an unseen person and 30 fps, fused with IMU pad impacts for confirmed punches; five adaptive sparring styles drive the robot's behaviour; a local Qwen2.5-3B LLM coach delivers real-time tips and post-session analysis; and a Vue 3 + FastAPI phone dashboard surfaces all of it without leaving the device.

Key Technical Contributions. The dual-branch voxel + pose Transformer architecture for early punch action prediction; the CV+IMU sensor fusion pipeline that turns ambiguous CV predictions into confirmed events through pad-constraint filtering; the Markov-chain sparring engine with weakness-biased opponent AI; and the fully on-device architecture (CV inference, LLM coaching, dashboard backend) that runs the entire training stack with zero internet dependency.
