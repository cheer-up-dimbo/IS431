6. Discussion and Future Work

6.1 Discussion

User Interface. The GUI passed all five functional requirements (GUI-1 through GUI-5), including multi-user data isolation, real-time session display, and hardware-independent development. The phone dashboard was developed as a companion interface after the CDE AI Fair revealed that touchscreen interaction with gloved hands was impractical.

Upper Mechanism. The 2-DOF coaxial differential arms, multi-layer padding with IMU sensing, and the CAN bus motor control architecture were validated through iterative prototyping. Arm strike speed (RM-5) and IMU impact detection rate (RM-6) are pending verification with the fully integrated prototype.

Lower Mechanism. The base passed stability testing (RM-1) with a factor of safety exceeding 1.5, and single-person portability (RM-7) was confirmed. Height adjustment stroke (RM-3) and yaw angular velocity (RM-4) are defined but pending verification. System integration tests (coordinated motion, loaded sparring, power budget) require the completed prototype.

Robot Intelligence. The CV pipeline exceeded its 90% accuracy target (RI-3, 96.8%) and met the 150 ms end-to-end latency requirement (RI-2, ~120 ms). All five AI sparring styles (RI-6) and the local LLM coaching system (RI-7) were validated through live deployment at the CDE AI Fair. The fair also drove key iterations: nearest-person tracking replaced background clutter filtering, and the transformer-based model replaced the original HSV colour tracking approach.

6.2 Current Limitations

Subsystem Limitation Impact
User Interface No formal usability testing with target users GUI was validated functionally and at showcases, but structured user studies with boxers of varying skill levels have not been conducted
Upper Mechanism Fixed head-torso pad separation (30 cm) Anatomical head-torso gap varies 26 to 33 cm across the 150 to 190 cm user range; fixed spacing is a compromise
Pending arm strike speed verification (RM-5) 90-degree strike in 0.25 s or less has not been measured on the integrated prototype
Lower Mechanism No linear forward/backward movement Robot cannot advance or retreat to maintain realistic sparring distance; limits footwork simulation
Robot Intelligence Single-camera viewpoint dependency Model is tightly coupled to the training camera angle; different viewpoints require re-recording the dataset
Block class underrepresentation (66.7% accuracy, n=6) Defensive pose classification is less reliable than offensive punches due to limited training samples
LLM coaching depth (3B model, 128-token cap) Adequate for real-time 1 to 2 sentence tips, but post-session analysis lacks depth and specificity

6.3 Recommendations for Future Work

Area Recommendation Rationale
User Interface Conduct structured user testing with boxers Formal usability studies across beginner, intermediate, and advanced boxers would validate training effectiveness and identify UX improvements
Upper Mechanism Variable head-torso pad separation A secondary actuator or adjustable rail would scale the head-torso spacing with user height (26 to 33 cm), improving anatomical accuracy
TPU lattice padding replacement A single-piece TPU honeycomb print could replace the foam, spring, and PLA mount, reducing part count and providing tuneable dampening (Di Caprio et al., 2025)
Lower Mechanism Add linear translation (forward/backward axis) Enables the robot to maintain or close distance, replicating a real opponent's ring movement and creating pressure-based training scenarios
Robot Intelligence Expand block training data and add multi-camera support More varied blocking samples would improve the 66.7% block accuracy. A second camera would resolve viewpoint ambiguity between similar punches
Upgrade LLM to a larger quantised model A 7B or 8B parameter model (still quantised to fit on-device) would generate richer post-session analysis and more specific drill suggestions

6.5 Conclusion

Project Outcome. BoxBunny addresses the gap identified in Chapter 2: no existing product consolidates adaptive fight intelligence, structured skill progression, realistic sparring, modular hardware, and performance analytics into a single platform. Of the 19 verification criteria defined across all subsystems, 15 have been verified and passed, with four mechanism-level requirements (RM-3 to RM-6) pending full prototype integration.

Subsystem Contributions. The User Interface delivers four training modes, multi-user accounts, and a phone dashboard across 24 GUI pages and 10 Vue views. The Upper Mechanism provides 2-DOF coaxial differential arms with impact-sensing padding. The Lower Mechanism provides a stable base (FoS exceeding 1.5), yaw rotation, and screw-jack height adjustment. The Robot Intelligence layer achieves 96.8% punch classification at 30 fps with CV+IMU sensor fusion and on-device LLM coaching.

Key Technical Contributions. The CV+IMU fusion pipeline for robust punch classification, the Markov-chain sparring engine with weakness-biased opponent AI, and the integrated on-device architecture that runs the full training stack without internet connectivity.
