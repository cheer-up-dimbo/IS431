5.3.3 Computer Vision & Action Recognition

The CV subsystem delivers three functions: the action prediction model (core), reaction time detection, and human tracking. The latter two consume processed frames from the action prediction pipeline rather than running independent perception stacks.

The action prediction model classifies 8 boxing actions (jab, cross, left/right hook, left/right uppercut, block, idle) in real time -- before the punch completes. It uses a single Intel RealSense D435i RGB-D camera mounted on the robot. Key constraints: punches travel toward the camera with heavy glove occlusion at extension, only the upper body is visible, and inference must run on an NVIDIA Jetson Orin Nano at 30fps.

5.3.3.1 Model Architecture

FusionVoxelPoseTransformerModel (~1.75M parameters)

The model combines two complementary ways of understanding a punch, then uses a Transformer to reason about how the motion unfolds over time.

Component Input Output Role
Voxel Branch 12³ 3D grid × 2 motion channels 192-dim Captures where the body moved in 3D space
Pose Branch 42 features from 7 body joints 64-dim Captures which body part moved and how
Fusion 256-dim (both branches combined) 192-dim Merges the two perspectives into a unified representation
Transformer 12 consecutive frames (0.4 seconds) 384-dim Reasons over how the motion unfolds across time
Classifier 384-dim summary 8 action classes Final prediction: jab, cross, hooks, uppercuts, block, or idle

Voxel Branch — 3D Motion Sensing

The depth camera sees the user in 3D. This branch divides the space around the user into a 12×12×12 grid of small cubes (each roughly 13cm), creating a 3D snapshot of where the body is at each moment. To detect motion, the model compares these snapshots across time using two channels:

  • Fast channel (2-frame difference, ~67ms) — detects the sudden onset of a punch
  • Slow channel (8-frame difference, ~267ms) — captures the full arc of the punch trajectory

Together, these two channels tell the model both when a punch started and what shape the motion followed — a hook sweeps horizontally while an uppercut rises vertically. A 3D convolutional neural network (Conv3D) compresses this spatial information into a compact 192-dimensional vector per frame.

Pose Branch — Body Joint Tracking

A YOLO pose estimation model (yolo26n-pose.pt) detects 7 upper-body joints (nose, shoulders, elbows, wrists) from the RGB camera image. From these joint positions, 42 features are computed: normalised coordinates, confidence scores, arm extension ratios, shoulder rotation, elbow bend angles, and joint velocities. The same YOLO model is used during both training and live inference to prevent any mismatch between the two.

Confidence Gating — Graceful Degradation

Boxing gloves frequently hide the wrist joints at the exact moment of punch extension — precisely when detection matters most. To handle this, the pose output is scaled by how confident YOLO is in its detections. When confidence is low, the pose signal is automatically suppressed and the model relies on the voxel branch alone. This fallback behaviour is reinforced during training by randomly dropping the pose input entirely for 15% of clips and zeroing individual joints 10% of the time, simulating real-world occlusion.

5.3.3.3 Data Collection and Training

Recording Infrastructure

A custom recording tool captures at 30fps (960×540 RGB + 848×480 depth) from a D435i mounted at ~1.5m height, 1-2m from the user.

Critical pipeline fix: Early recordings silently dropped depth frames (~15fps actual vs 30fps expected) because the laptop could not write float32 depth arrays to an external SSD fast enough. The fix: a dedicated capture thread running independently of disk I/O, an async writer thread with a 300-frame queue buffer, non-blocking enqueue, and frame-drop diagnostics. All early data had to be re-collected and re-annotated from scratch.

Annotation

A custom timeline-based annotation tool (annotate_punches_gui.py) with drag-to-resize segments and auto-save every 30 seconds. Punch segments span from the first preparatory cue (shoulder drop, hip rotation) to full extension -- retraction is excluded because it looks similar across punch types.

Block annotation fix: Initially, block annotations covered only the onset (arms rising). This made block onset indistinguishable from uppercut onset, hurting live inference. Extending annotations to cover the full guard sequence (rise, hold, return) dramatically improved live block detection — v10 had 97.3% validation accuracy but poor live blocks; v11 had 96.8% validation but substantially better live performance due to this fix alone. Block accuracy remains the lowest at 66.7% in validation due to having only 6 samples (the smallest class), but its real-world usability improved significantly with the annotation change.

Dataset

808 training segments from 2 people (7 clips) + 128 validation segments from 1 unseen person (1 clip), across 8 action classes. Class imbalance mitigated with balanced sampling and focal loss (γ=1.5).

Data quality over architecture: Removing one person's inconsistent data improved accuracy from 92.8% to 97.3% (+4.5%) -- larger than any architecture change across 6 models tested. This was the single biggest accuracy gain in the project.

Training

Parameter Value
Epochs 300 (early stop patience 60)
Batch size 16
Optimiser AdamW (LR 0.0005, weight decay 0.01)
LR schedule Warmup 20 epochs → cosine decay to 1e-6
Loss Focal loss (γ=1.5) + label smoothing (0.03)
Best epoch 73 / 133 trained

Key augmentation -- horizontal flip (50%): exploits boxing's left/right symmetry by flipping the voxel X-axis, swapping left/right pose features, and swapping labels (jab↔cross, left_hook↔right_hook, left_uppercut↔right_uppercut), effectively doubling the dataset. Other augmentations: speed (0.8-1.2×), voxel shift/cutout/stretch, multi-window (9, 12 frames).

5.3.3.4 Ablation Study

Mode Validation Accuracy What It Captures
Pose only 44.1% Joint positions but no spatial/3D motion context
Voxel only 80.6% 3D motion trajectories but cannot distinguish left from right
Both fused 97.3% Complete picture -- spatial motion + joint-level discrimination

The branches provide genuinely complementary information. Without pose, 34% of jabs were misclassified as cross because both produce identical "straight forward" voxel patterns -- only wrist positions from the pose stream reveal which hand is punching. The voxel branch in turn captures 3D arc trajectories that distinguish hooks from uppercuts, which 2D pose alone cannot represent. Fusion eliminated left/right confusion completely, yielding a +16.7% gain over voxel-only.
