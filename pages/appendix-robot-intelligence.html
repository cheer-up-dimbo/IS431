B. CDE Fair CV Pipeline

The CDE Fair version used HSV colour-based glove tracking as the primary detection method. The Transformer model was not ready in time. This pipeline was replaced entirely in the final system.

C. ROC Curves

One-vs-rest ROC curves for each action class plus the micro-averaged curve. Micro-averaged AUC of 0.999 indicates near-perfect class separability across all 8 actions.
