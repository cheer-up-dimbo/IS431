A. Detailed Feature Exploration — 9 Iterations

Iteration 1: 2D Pose Estimation (YouTube + LSTM/GCN)

Goal: Validate the pipeline using publicly available YouTube boxing videos.

  • Features: 17 COCO keypoints via YOLO-Pose, encoded as 12-channel skeleton features (joint coordinates, bone vectors, temporal derivatives, bone motion)
  • Models tested: LSTM (best on small dataset), AAGCN (~2.5M params, 10 GCN blocks with adaptive graph learning), ST-GCN, ST-GCN++
  • Result: High accuracy on YouTube data, validating the pipeline concept
  • Why it failed: YouTube filming angles did not match the robot-mounted camera perspective. The model could not transfer.

Iteration 2: 3D Pose Estimation (RealSense Depth Lifting)

Goal: Self-recorded D435i data with depth-based 3D skeleton reconstruction.

  • Features: 2D keypoints lifted to 3D using depth maps with skeleton constraints (arm Z-coordinate refinement, temporal interpolation)
  • Models tested: AAGCN, MotionBERT (abandoned), PoseC3D
  • Result: ~67% accuracy after extensive constraint tuning
  • Why it failed: Boxing gloves occlude wrist keypoints during punches — exactly when detection matters most. Depth holes and fast motion blur compounded the problem.

Iteration 3: Raw RGBD Frames + Pretrained 3D CNNs

Goal: Bypass pose entirely — learn from raw pixels via transfer learning.

  • Features: 4-channel input (RGB + normalised depth), person-cropped to 112×112
  • Models tested: Swin3D-B (~88M params, Kinetics-400 pretrained), MViT V2, R3D-18 (~33M params)
  • Why it failed: 33–88M parameters, far too large for edge hardware. Batch size 2 on Colab, slow and unstable.

Iteration 4: RGBD + Segmentation + Causal Transformer

Goal: Efficient spatial encoding with temporal transformer reasoning.

  • Features: YOLO segmentation masks, EfficientNet-B2 encoder (frozen, 512-dim per frame)
  • Architecture: CausalActionTransformer — 6 causal layers, 8 heads, ~3M trainable / ~35M total
  • Innovation: Progressive prediction loss — classification at ALL timesteps, not just the final frame
  • Why it failed: Still pixel-based, still required Colab for training.

Iteration 5: Depth Feature Engineering (Z-Mask)

Goal: Strip away RGB, focus on handcrafted depth features.

  • Features (1,156 dims/frame): 12×12 depth grid (144), RGB grid (432), centre of mass (2), velocity derivatives (578)
  • Architecture: BoxingCAT — 1D conv stem, 4 causal transformer layers, self-supervised future prediction head
  • Why it failed: 2D depth grid lost critical 3D spatial info. Hooks vs uppercuts indistinguishable.

Iteration 6: Voxel + Colour Tracking (~68%)

Goal: 3D voxel motion + explicit hand tracking via coloured gloves.

  • Features (1,749 dims/frame): 12³ voxel delta (1,728), optical flow (2), glove colour tracking (18 dims — 3D positions, velocities, depth validity per hand), foreground ratio (1)
  • Architecture: VoxelFlowModel (~1.2M params) — Conv3D voxel branch + MLP flow + MLP glove, concatenation fusion
  • Result: ~68%. Multimodal combination outperformed either branch alone.
  • Why it failed: Required coloured gloves (red/green). HSV tracking unreliable with variable lighting.
  • Key insight: Confirmed voxels need hand/joint information to distinguish punch types.

Iteration 7: Voxel-Only Causal Transformer (80.6%)

Goal: Test whether voxels alone could be sufficient.

  • Features (55,296 dims/frame): 24³ grid × 4 channels (occupancy delta + directional gradients dx, dy, dz)
  • Architecture: CausalVoxelTransformerModel (~2M params) — Conv3D stem, 4-layer causal transformer
  • Result: 80.6% — but 19/56 jabs misclassified as cross (34% error)
  • Why it failed: Jab and cross produce identical "straight forward" voxel patterns. Directional gradients could not solve left/right confusion.

Iteration 7b: Voxel Optimisation for Real-Time

Goal: Reduce dimensions for real-time inference.

  • Changes: Grid 24³ → 12³ (55,296 → 17,280 dims). Multi-scale deltas (fast 67ms + slow 267ms). Channel_p90 normalisation.
  • Impact: Dramatically faster extraction (~13cm per voxel, sufficient for punch trajectories). Established the 12³ grid used in all subsequent iterations.

Iteration 8: Voxel + Pose Fusion — Breakthrough (97.3%)

Goal: Revisit pose as a lightweight complement to voxels.

  • Features (3,480 dims/frame): 12³ × 2 channels voxel (3,456) + 24-dim YOLO pose. Gradients removed — pose makes them redundant (5× reduction).
  • Key innovations: Confidence gating, pose dropout (30% clip + 20% joint), YOLO bbox masking of background people
  • Result: 97.3% — eliminated left/right confusion entirely (19 errors → 0)
  • Full circle: Pose from Iteration 1 returned as a complement, now tolerant of occlusion.

Iteration 9: Production Deployment (v11, 96.8%)

Goal: Jetson Orin Nano deployment + fix live inference issues.

  • Enhanced pose: 24 → 42 dimensions (added elbow angles, joint velocities, extension rates)
  • Block fix: Annotations extended to full guard sequence. v10 had 97.3% but poor live blocks; v11 has 96.8% with correct detection.
  • Training: Horizontal flip (doubles dataset), focal loss (γ=1.5), class-balanced sampling
  • Deployment: TensorRT FP16, parallel worker threads, RollingFeatureBuffer with strict ordering
