5.3.5 Dashboard & Analytics

Beyond core intelligence, BoxBunny provides a software layer that transforms raw training data into actionable insights, delivers AI coaching analysis, and enables convenient remote control.

5.3.5.1 Communication Architecture

The system uses a 3-layer communication architecture connecting the desktop GUI, phone dashboard, and ROS 2 backend:

Layer From → To Method
ROS Bridge GUI ↔ ROS Core QThread, Qt signals, async services
IPC Files Dashboard ↔ GUI JSON files in /tmp/, 100ms polling
REST + WS Dashboard ↔ Backend HTTP API + WebSocket real-time

The phone dashboard is accessible over the robot's WiFi access point. Users control BoxBunny from their phone — no typing on a 7-inch touchscreen with boxing gloves, no bending down, and natural mobile interaction for chatting with the AI coach.

5.3.5.2 Analytics & Performance Insights

All training data flows through the system into meaningful user insights:

  • Session-Level Analytics: Each session publishes a SessionPunchSummary with 20+ fields — punch distribution by type, force levels, pad distribution, rounds completed, punches per minute, max power, and movement metrics. Stored in per-user SQLite for long-term tracking.
  • Trend Analysis: Time-series analytics across four periods (7/30/90 days, all time) for five metrics: volume, reaction time, power, defence rate, and stamina.
  • Peer Comparison: Population benchmarks by age, gender, and skill level across 6 metrics. Tiers range from "Getting Started" (<10th percentile) to "Elite" (>90th).
  • Personal Records: All-time bests for power, stamina, and reaction time tracked in a dedicated personal_records table and surfaced with the date achieved.
  • Sparring-Specific: Defence breakdown (blocks, slips, dodges, hits received) and weakness profile revealing which punches the user struggles to defend — the same data driving the AI sparring engine's targeting.

5.3.5.3 AI Coach Analysis & Training Suggestions

  • Post-Session Analysis: The LLM receives the full SessionPunchSummary and generates a 2–3 paragraph analysis referencing specific metrics, weak areas, and improvement trends.
  • Actionable Drill Suggestions: The LLM outputs structured tags ([DRILL:Name|combo=1-2|rounds=2|work=60s|speed=Medium]) parsed into clickable cards that launch the suggested configuration with one tap.
  • Interactive AI Chat: Full-screen chat with word-by-word streaming (20ms/word). Users ask technique questions, request training plans, or get stat explanations. History is persisted with follow-up suggestions after each response.
  • Convenience Design: Users chat from their phone instead of the 7-inch touchscreen. This was directly motivated by CDE AI Fair feedback where touchscreen typing was a friction point.

5.3.5.4 Phone Dashboard Features

The phone dashboard is a Vue 3 SPA (Composition API, Pinia, Tailwind CSS, Chart.js) served by a FastAPI backend. Key views:

  • Dashboard Home: XP progress ring, weekly goal with streak counter, training heat map, quick stats with trend arrows, peer comparison bars, recent session card, and AI coach quote of the day.
  • Performance: Trend charts across selectable periods for all 5 key metrics with personal best callouts.
  • Training Remote: Quick preset grid for one-tap session start, navigation buttons to remotely control the GUI, and press-and-hold height adjustment. Users configure their session from their phone and walk to the robot ready to go.
  • Coach View (coach accounts only): Group circuit training dashboard — manage participant rotation, view live stats, load presets, and review past sessions.

5.3.5.5 API & Database Design

FastAPI Backend (7 routers under /api/)

Router Key Endpoints Purpose
auth login, signup, pattern-login, profile JWT auth (7-day TTL) + SHA-256 pattern lock
sessions current, history, trends, detail, raw Session data with pagination and mode filtering
gamification profile, achievements, leaderboard, benchmarks XP, ranks, badges, peer comparison
chat status, message, history LLM coaching via ROS service bridge
remote command, height, presets GUI remote control via IPC files
presets list, create, update, delete, favourite Training preset management
coach load-config, start/end-station, live, sessions Group training management (coach role)

Two-Tier SQLite Database

  • Main DB (boxbunny_main.db): Shared tables for users (password hash + pattern lock), auth sessions, training presets, and coaching sessions.
  • Per-User DB (users/{username}/boxbunny.db): Isolated tables for training sessions, events, combo progress, performance tests, sparring, weakness profiles, and gamification (XP, achievements, streaks, records).
  • Design rationale: Per-user databases provide data isolation, enable concurrent writes without lock contention, and simplify backup and export.

WebSocket

Real-time session updates via ws://<host>:8080/ws with events for session started/stats/completed. Uses 30-second keepalive ping/pong and automatic reconnection with exponential backoff (max 10 attempts) plus state sync on reconnect.

5.3.5.6 Gamification System

6 Rank Tiers

Rank XP Threshold
Novice 0
Contender 500

XP Calculation

Base XP varies by mode (Training 50, Sparring 80, Free 30, Performance Tests 40) with bonuses for completion and score. Difficulty multipliers: 1.0× Beginner, 1.3× Intermediate, 1.6× Advanced, 2.0× Elite. Minimum 10 XP per session.

12+ Achievements

Including "First Blood" (first session), "Century" (100 punches), "Speed Demon" (lightning reaction), "Weekly Warrior" (7-day streak), and "Perfect Round" (100% accuracy). Each badge awarded only once.

Streaks & Goals

Daily training streak tracking with longest streak records. Configurable weekly goal (default 3 sessions/week) with progress tracking.
