Testing & Evaluation

This section presents the performance criteria, test procedures, results, and limitations of the Upper Mechanism. Each test maps directly to a design specification established in the Design & Ideation phase.

Performance Criteria

The following measurable targets were established from the torque calculations (Appendix 1) and padwork research:

ID Criterion Target How Measured
PC-1 Strike speed (90° rotation) ≤ 0.25 s High-speed video + firmware timestamp delta
PC-2 Positional repeatability ≤ 10 mm spread over 10 reps Laser pointer + target sheet
PC-3 IMU strike detection rate ≥ 95% true positive 60-punch controlled test
PC-4 Sparring endurance 10 min continuous, <60°C motors Continuous sparring + temperature log
PC-5 Impact force differentiation Monotonic increase: light < medium < heavy IMU L2 vector norm (3 users)
PC-6 FSM multi-strike chain 3-strike chain ≤ 5 s total Video + FSM console log
PC-7 Regenerative braking safety No PSU trip over 5 emergency stops Visual confirmation + voltmeter
PC-8 Micro-ROS auto-recovery Reconnect within 3 s of agent restart Kill agent + timer + GUI status bar
PC-9 Current-limit safety cutoff Motors disable within 100 ms of breach Physical obstruction + Analytics trace
PC-10 ROS external command execution Correct strike on /robot/strike_command Terminal command + video + feedback echo

Limitations

  • Regenerative braking: Software PWM ramp-down mitigates OVP trips but a hardware TVS clamp remains required for full protection under extreme loads.
  • 3D-printed durability: Key load-bearing gears are polymer FDM prints. Long-term fatigue under repeated high-velocity impacts has not been characterised.
  • IMU MEMS drift: Velocity integration was abandoned due to thermal random-walk drift; the system relies on peak-vector magnitude tracking only.
